The `moglang` organization maintains a growing set of packages separately from
the runtime. They use canonical `github.com/moglang/...` imports and are
versioned independently, so check each repository's Releases page when choosing
a version.

dependency builds them from source; configured registries may provide prebuilt

## Install and import

Choose a tag from the package repository, add it to your project, and import
the canonical module path. For example:

```bash
mog add github.com/moglang/json@v0.2.0
```

```rust
const json = @import("github.com/moglang/json")
var value json.Json = json.parse("{\"language\":\"Mog\"}")
print(json.stringify(value))
```

`mog add` updates `mog.toml`, resolves the package, installs it, and updates
`mog.lock`. Commit the lockfile for applications.

<Aside type="note" title="Two different math examples">
	The official source package is imported as `github.com/moglang/math`. The
	bare `math` import used in the native-package guide is a small reference
	package built inside the Mog runtime repository; it is intentionally separate.
</Aside>
